ProBeam Lighting — Product Datasheets
=====================================

382 products, one folder per PBL code. Each folder holds:
  - ProBeam_<PBL>_Datasheet.pdf   (print-ready)
  - ProBeam_<PBL>_Datasheet.docx  (editable)
  - product.json, photo.png, dimension.png (source parts)

INDEX.csv            - every PBL code mapped to its 3A code, category, variant count.
_photo_review_ALL.csv - products whose catalogue photo is a wide/unclear crop and
                        should be replaced in the web-photo pass.

Specs are pulled from the 3A Lighting 2025-26 catalogue. Datasheets show PBL codes only
(no supplier codes). Compliance icon strip is not included (needs the LW-01 W3 template).
